## How to Use

### Option 1: Test Locally (Now)
App is running at: **http://localhost:8501**
- View executive dashboard
- Ask business questions
- Generate leadership summaries
- Check system status

### Option 2: Deploy to Cloud (2 minutes)

#### Streamlit Cloud (Recommended)
1. Push to GitHub
2. Visit share.streamlit.io
3. Connect your repo
4. Add secrets (API key, board IDs)
5. Deploy

**Public URL**: `https://[username]-[appname].streamlit.app`

#### Heroku
1. `heroku login`
2. `heroku create [app-name]`
3. Set config vars with API key
4. `git push heroku main`

**Public URL**: `https://[app-name].herokuapp.com`
